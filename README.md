Site pra encontrar salas desocupadas para estudar no [Insper](https://insper.edu.br/).

Esse projeto é uma **continuação do projeto original criado pelo Pedro Fracassi**, disponível em
[github.com/pedrofracassi/insper-salas-livres](https://github.com/pedrofracassi/insper-salas-livres).
Ele deixou a codebase aberta quando se formou, pra que outros alunos pudessem contribuir ou fazer forks.

> [!CAUTION]
> Esse projeto foi criado com base em um endpoint de API do Insper não documentado, tirado [da página de agenda](https://cgi.insper.edu.br/Agenda/) (abre, aperta F12 e dá uma espiada na aba de Rede).
>
> Embora a página e o endpoint sejam públicos, tome cuidado para não spammar ele e acabar deixando alguém do TI bravo.

## Como rodar o projeto

```bash
npm install
npm run dev
```
